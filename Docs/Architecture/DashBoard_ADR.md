# ADR 2: DashBoard Technology

## Purpose Of the document
This document proposes several dashboard technology options to help with the development of the UI.

## Status : Proposed

## Context 

This project is requires a robust and repsonsive DashBoard UI. It would be possible to create our own UI in react from scratch, however, it May be simplier to use a Dashboard template/Technology in order to speed develpment. For The main way to judge these options is based on cost and the experince of the team. 

| Option | Parent Company/ Organization| Cost | Team Experince|
|--------|-----------------------------|------|---------------|
| Sync Fusion | Private                | $959/developer/year | 0 |
| MUI UI| Private nonprofit/Company | Free | 0 | 
| Tail Admin| Private Company | Free-Open Source - Pro Versions | 0 | 

A few things are immidiatly clear. Sync Fusion is far outside of any budget this project has, especiialy when we have other free options. This document Suggest MUI UI. It is completely free and open surce while a a lot of comunnity support and and documentation. It also comes with templates that we can put into our priject direclty to further speed up development time.
